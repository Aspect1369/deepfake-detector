How does the pulse estimate work?

The preview stays in your browser. When you select Analyze, JavaScript sends the video in FormData to the local Node server, which calls the Python detector:

async function sendVideo(selectedVideo) {
  const formData = new FormData();
  formData.append("video", selectedVideo);

  const response = await fetch("/api/analyze", {
    method: "POST",
    body: formData
  });
  if (!response.ok) throw new Error("Upload failed");
  return response.json();
}

FormData packages the video under the field name video. Python tracks a face with OpenCV, averages green-channel values in forehead and cheek regions, filters the traces from 0.7 to 3.3 Hz, and estimates a pulse peak. SQLite stores the measured BPM and signal-quality details; the server deletes the temporary video. The quality score is not a probability that the video is real or fake.

PulseCheck is a learning demo, not a forensic tool.
